# ADR-0054: CI and release v3 — feature matrix, fast smoke test, cross-OS determinism

- **Status:** Superseded by ADR-0060
- **Date:** 2026-10-15
- **Milestone:** M1 (jobs), M5 (cross-OS determinism becomes blocking)
- **Supersedes:** ADR-0038 (keeps the three-OS `check` matrix, toolchain pinning, sim
  isolation, release targets and packaging, nightly workflow)

## Context

Review findings G-W11, G-P2, G-P4, F-1, G-D (cross-platform goal): `--all-features` would
enable `trace_tracy` (C++ build) and unfinished features on three OSes; a 300-frame release
smoke test on lavapipe at full resolution costs 15–30 min per push; CI duration was
unbounded; outages had no policy; ADR-0043 now requires cross-OS determinism verification.

## Decision

- **Feature matrix** (never `--all-features`): clippy and tests run twice per OS —
  default features, and `--features dev`. `inspector` joins the matrix once it exists;
  `trace_tracy` builds only in the nightly workflow on Linux.
- **Render smoke** (Linux, blocking): `xvfb-run cargo run -p cb_game --profile ci-release --
  --smoke-test 60 --resolution 640x360 --scene smoke` with the build cached; the smoke scene
  contains one instance of every material/specialization (extended each milestone by the
  milestone-completion skill). macOS smoke stays informational.
- **Cross-OS determinism** job: each OS runs `cargo run -p cb_sim --release --example
  determinism_probe` (worldgen hash for 5 seeds + 2-game-day scripted scenario hash with
  traffic on) and uploads the hashes; a final job compares them. Informational M1–M4, blocking
  from M5 (failure → fix or fall back per ADR-0043 with a new ADR).
- **Duration target**: the full pipeline ≤ 25 min wall on all OSes; caches keyed by OS + arch +
  lockfile + profile; `ci-release` profile = release with `debug = false`,
  `codegen-units = 16`, thin LTO off.
- **Outages**: if a runner is unavailable or queued > 60 min, the milestone may be marked
  "done — CI pending" in PROGRESS.md; the agent re-checks on the next session and before the
  next milestone completes.
- Release workflow unchanged from ADR-0038.

## Consequences

- Predictable CI time, no accidental C++ toolchains, enforced portability of simulation results.
